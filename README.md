# WPS / PPT 演讲备注悬浮窗 (`wps-notes-overlay`)

专为 **macOS 单屏演讲 / 线上会议投屏** 打造的轻量级演讲者备注悬浮提词器。  
当你在 **飞书会议、腾讯会议、会议室投屏** 中演示 WPS 或 PowerPoint 幻灯片时，**只有你自己的屏幕上看得到备注悬浮窗，参会观众的共享画面里完全隐身**。

---

## ✨ 功能亮点

- **🔒 投屏隐身（别人看不到你的备注）**  
  基于 macOS 原生 `AppKit` 的 `NSWindowSharingNone` 属性，悬浮窗默认从飞书会议、腾讯会议等屏幕共享流中隐藏。你在本机看着提词稿从容演讲，观众只看得到干净的幻灯片。
- **📌 强力置顶，不抢焦点**  
  采用 `NSPanel`（`NonactivatingPanel` + 超高窗口层级 + 自动置顶守护），在幻灯片播放过程中稳稳浮在最上层，不会一翻页就被压到后台。
- **⌨️ 智能按键同步（打字绝不误触）**  
  支持 `Space`（空格）、`←`、`→`、`PageUp`、`PageDown` 翻页。**智能识别当前前台应用**：只有在悬浮窗激活，或当前前台是 **WPS / PowerPoint** 时按键才会翻页；当你切到飞书、微信或浏览器回复消息敲空格时，**绝不会误触翻页**。
- **⚡ 秒开几百 MB 的超大 PPT**  
  内置轻量级 OOXML (`ZIP + XML`) 流式解析器，只提取幻灯片顺序与备注文本，完全跳过高清大图和视频解压，200MB+ 的 `.pptx` 也能 1 秒加载。
- **🔢 支持随机跳页 & PowerPoint 自动跟页**  
  - **WPS 演示**：平时按空格/方向键即可同步翻页；若演示中途跳页，可在悬浮窗输入页码点 **「跳转」** 立即对齐。
  - **Microsoft PowerPoint**：除按键同步外，还支持通过 AppleScript 自动感知当前放映页码，缩略图跳页自动跟随。

## 🚀 Mac 一键安装

### 环境要求
- macOS 12 及以上（推荐 macOS 13 / 14 / 15）
- Python 3.9+（macOS 自带 Xcode Command Line Tools 或 Homebrew Python 均可）

### 安装步骤

1. **克隆或下载本仓库**：
   ```bash
   git clone https://github.com/TinaSong0590/wps-notes-overlay.git
   cd wps-notes-overlay
   ```

2. **一键安装并生成桌面快捷方式**：
   - **方法 A（双击安装）**：在 Finder 中直接双击仓库根目录下的 `install_mac.command`。
   - **方法 B（终端安装）**：
     ```bash
     bash scripts/install_mac.sh
     ```

安装完成后，你的 **桌面 (Desktop)** 会自动生成两个快捷入口：
- 🖥️ **`WPS备注悬浮窗.app`**：双击即可启动；也可以**直接把任意 `.pptx` 文件拖拽到该图标上**直接打开对应备注！
- 📜 **`打开WPS备注悬浮窗.command`**：终端快捷启动脚本。

## 📖 使用方法

### 1. 打开你的演示文稿备注
- 双击桌面的 **`WPS备注悬浮窗.app`**，点击悬浮窗左上角的 **「打开…」** 按钮，选择你正在演示的 `.pptx` 文件；
- 或者直接把 `.pptx` 文件拖到 **`WPS备注悬浮窗.app`** 图标上；
- 也可以在终端指定文件启动：
  ```bash
  ./.venv/bin/wps-notes-overlay /path/to/your-slides.pptx
  ```
  > 💡 仓库自带一份示例文稿 `samples/demo-notes.pptx`，可直接打开体验。

### 2. 在飞书会议 / 腾讯会议中开始演示
1. 先打开备注悬浮窗并加载 `.pptx`，用 **`A-` / `A+`** 调整到舒适的字号，拖到屏幕顺手的位置；
2. 打开 WPS 或 PowerPoint 开始放映幻灯片（**推荐用「窗口放映 / 浏览视图」**，见下方常见问题）；
3. 在飞书会议 / 腾讯会议中开启共享屏幕（**推荐优先选择「只共享 WPS/PPT 窗口」**，双重保险）；
4. 在 WPS / PowerPoint 中正常按 **空格键 (`Space`)** 或 **左右方向键 (`←` / `→`)** 翻页，悬浮窗备注会自动同步翻页！

## ⌨️ 工具栏与快捷键说明

| 按钮 / 快捷键 | 功能说明 |
| :--- | :--- |
| **`打开…`** | 选择并加载 `.pptx` / `.ppsx` / `.pptm` 文件的演讲者备注 |
| **`←` / `PageUp`** | 上一页备注（在悬浮窗或 WPS/PPT 前台时按键生效） |
| **`→` / `Space` / `PageDown`** | 下一页备注（在悬浮窗或 WPS/PPT 前台时按键生效） |
| **`页码` + `跳转`** | 输入目标页码（如 `12`）并点击「跳转」，快速对齐随机跳页 |
| **`重载`** | 当你在 WPS/PPT 中修改并保存了备注后，点击即可重新读取最新备注 |
| **`A-` / `A+`** | 缩小 / 放大备注正文字号（支持 10pt ~ 48pt） |
| **`隐私`** | 查看投屏隐身原理与安全共享建议 |
| **`置顶`** | 手动强制把悬浮窗重新拉回最顶层 |
| **`关闭` / 左上角红灯** | 彻底卸载按键监听并退出悬浮窗程序 |

### 系统权限说明（macOS）
为了让悬浮窗在你聚焦 WPS / PowerPoint 放映时也能响应翻页按键：
- 首次运行时，若 macOS 弹出 **「辅助功能 (Accessibility) / 输入监控」** 权限提示，请前往 **系统设置 → 隐私与安全性** 勾选允许你所使用的终端或 `WPS备注悬浮窗.app`。
- 若未授予全局按键权限，你仍然可以直接点击悬浮窗上的 `←` / `→` 按钮或聚焦悬浮窗按方向键翻页。

## ❓ 常见问题 (FAQ)

### Q1：为什么点击 WPS「幻灯片播放」后，悬浮窗还是被挡住了？
**原因**：WPS 默认的「全屏放映」使用的是 macOS **独占全屏空间 (Exclusive Fullscreen)**，它会独占整个显示层。  
**解决办法（二选一）**：
1. **推荐**：在 WPS 中使用 **「窗口放映 / 浏览视图」**（或在网页版 / HTML 演示模式下播放），这样悬浮窗会稳稳浮在幻灯片上方；
2. 在飞书 / 腾讯会议中 **只共享 WPS 窗口**，本机桌面即可正常看到悬浮窗。

### Q2：飞书会议室无线投屏（输入投屏码 / 会议 ID）可以用吗？
**可以用**。无线投屏码同样基于本机画面采集，悬浮窗开启了 `NSWindowSharingNone`，大屏上不会显示备注。在会议室场景下，同样建议采用 **「WPS 窗口放映 + 只投 WPS 窗口」**，稳定性最佳。

### Q3：我的文稿是旧版 WPS `.dps` 格式怎么办？
旧版 `.dps` 是私有二进制格式。请在 WPS 中打开该文件，点击 **「文件 → 另存为」**，选择 **PowerPoint 演示文稿 (`*.pptx`)**，然后用本工具打开 `.pptx` 文件即可。
